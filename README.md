## Website

Next.js, TypeScript and Tailwind CSS with a static export deployed on Vercel. The approved visual identity uses locally hosted fonts and responsive editorial layouts.

```sh
pnpm install --frozen-lockfile
pnpm build
```

Set `NEXT_PUBLIC_SITE_URL` and `ALLOW_INDEXING` as documented in `.env.example`. Production uses the public portfolio origin. Local previews can use indexing disabled. No service credentials are needed to build or view this static website.
